# Lembar ikon (Gemini)

Ikon UI dibuat dengan Google Gemini (akun pemilik), 4x4 per lembar, lalu dipotong dengan
`Tools/Python/slice_icon_sheet.py` ke `Content/Data/Icons` (128 px, sudut transparan).
File di sini versi 1024 px; versi asli 2048 px tidak disimpan.

Urutan nama per lembar (kiri ke kanan, atas ke bawah, `-` = tidak dipakai):

- `gemini_sheet1.jpg`: app_ojekku, app_pesan, -, -, app_dompet, app_galeri, app_peta, bab1, bab2, bab3, bab4, bab5, status_selesai, status_terkunci, status_sekarang, stat_diawasi
- `gemini_sheet2.jpg`: app_kicau, app_berita, stat_uang, stat_suara, stat_energi, item_beras, item_obat, item_masker, item_nasi_bungkus, item_kopi, menu_lanjut, menu_simpan, menu_muat, menu_pengaturan, menu_keluar, menu_jurnal
- `gemini_sheet3.jpg`: menu_utama, menu_baru, menu_kredit, menu_petabab, menu_toko, item_dokumen, item_kunci, item_pemancar, -, item_petisi, item_piring, item_rekaman, item_koran, item_foto, item_surat, item_laporan
- `gemini_sheet4.jpg`: item_pamflet, item_gorengan, ui_spn, ui_jam, ui_order, ui_satir, app_ponsel, ui_stempel, ui_asap, tempat_sekolah, tempat_puskesmas, tempat_dewan, ui_helm, ui_peringatan, ui_malam, ui_siang

Di lembar 3, tile selebaran bertulisan diganti versi lembar 4.
